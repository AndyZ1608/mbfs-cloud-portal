# Edit Network policy

CMP edits only current-project, non-shared, non-external Neutron Networks. Opening Edit loads fresh Network, Subnet, Router, and router-interface Port data. Saving reloads them again, checks resource ownership and available revision numbers, validates all requested fields, then issues only the changed Neutron updates. CIDR, IP version, provider fields, `shared`, and `router:external` are never accepted as edits. UUIDs identify resources but cannot be changed.

The UI reads `GET /api/networks/:id/edit` and sends one `PATCH /api/networks/:id` with the desired Network name, its revision number, and an explicit list of every Subnet's UUID, revision number, name, Gateway, DNS list, allocation pools, mode, and Router UUID (or `null` for Isolated). The browser never performs the Neutron sequence itself or supplies a project ID.

Every Subnet on a Network has its own edit panel and Routed/Isolated choice. Routing is inferred from Neutron router-interface Ports and their `fixed_ips[].subnet_id`, not from names. CMP refuses to edit topology it cannot attribute to a single current-project Router. The backend uses Neutron's subnet-ID add/remove interface operations. A Router move detaches the old Router, attaches the new one, and attempts to restore the old attachment if the new attach fails. Other successful updates are also rolled back in reverse order on failure. If rollback fails, or a provider timeout/5xx leaves the in-flight operation uncertain, CMP returns a partial-failure error with safe Network/Subnet IDs; operators must inspect live Neutron state before retrying.

DHCP is informational only: the edit request cannot include `enable_dhcp`. Existing legacy Subnets with DHCP disabled retain that state; editing does not silently enable DHCP or offer a disable control. CMP supports editing Gateway addresses for IPv4/IPv6 and IPv4 allocation pools with basic bounds/overlap validation; Neutron remains authoritative, especially when IPs are already allocated. IPv6 allocation pools are read-only in this UI. DNS and Subnet names remain editable. No Port or allocated IP is deleted by this workflow.
